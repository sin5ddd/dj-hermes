# strudel-rs — リアルタイム演奏システム最終型（Rust・デュアルデッキ・バークオンタイズ）Implementation Plan

> **For Hermes:** Load the plan-execution-loop skill and implement this plan task-by-task.

**Goal:** Strudel 記法で書かれた「曲ファイル」を、Rust 製 CLI アプリがリアルタイム演奏する。人間はエディタでファイルを編集すると**小節境界でシームレスに反映**され、LLM は HTTP API / MCP からワンショットまたはストリームで演奏を操作できる。曲A・曲Bを同テンポで並行再生可能にし、**ミキサー層**で音量・EQ/フィルター・切替を行う。

**Architecture:**

```
入力面（3系統・すべて同じ Command チャネルへ）
┌─────────────────────────────────────────────────────────┐
│ 人間A: エディタで songs/*.strudel を保存 → notify crate   │
│        が検知 → バー境界でホットリロード                  │
│ 人間B: REPL (rustyline) — デッキ/ミキサー操作コマンド     │
│ LLM  : HTTP API (axum) + MCP (rmcp, stdio→HTTP ブリッジ) │
└──────────────────────┬──────────────────────────────────┘
                       ▼ Command (crossbeam SPSC)
              ┌─────────────────┐
              │  Scheduler      │  バー境界でのみ状態遷移
              │  (audio thread) │  pending_code / pending_song / mixer を管理
              └────────┬────────┘
                       ▼
        Deck A ◄──同一 Transport(共有時計)──► Deck B
        (曲A voices)                          (曲B voices)
                       ▼
              ┌─────────────────┐
              │  Mixer 層       │  A/B 音量フェーダー・EQ/フィルター
              │                 │  クロスフェード / 曲切替
              └────────┬────────┘
                       ▼
                  AudioBackend (CPAL) → 出力 (ALSA)
```

**中核概念:**

- **曲 (Song)**: `.strudel` ファイル1つ = 1曲。複数の名前付きパターン（トラック）を持つ:
  ```
  // songs/techno1.strudel
  bpm: 126
  ---
  kick:  s("bd*4").gain(0.9)
  bass:  note("c2 c2 eb2 g2").s("sawtooth").lpf(400).gain(0.7)
  hat:   s("hh*8").gain(0.3)
  lead:  note("<c4 eb4 g4 bb4>").s("square").lpf(2000).gain(0.4)
  pad:   note("c3'maj").s("triangle").lpf(800).gain(0.35)
  ```
  ヘッダに `bpm`、以降 `名前: パターンコード` の行。`#` コメント可。
  Strudel 記法をできるだけそのまま流せる方針。**和音記法（`c3'maj` / `c3'maj7` 等）も初期から対応**する。
- **デッキ (Deck)**: Song をロードして鳴らす再生ユニット ×2（A/B = 曲A・曲B）。両デッキは**同一 Transport（共有グローバル時計）**を参照するため、BPM が同じならバーが完全同期する。BPM が違う場合はマスター BPM（Transport 側）に統一される（曲ファイルの bpm は「マスター未設定時の初期値」として扱う）。
- **ミキサー層 (Mixer)**: 曲A/B の「上」に乗る第3の層。担当は (1) A/B それぞれの音量フェーダー (2) EQ・フィルター (3) A/B のクロスフェードおよび曲切替。デッキは「何を鳴らすか」、ミキサーは「どう混ぜて出すか」。
- **バークオンタイズ (Bar-Quantized Transition)**: コード変更・曲切替・ミュート解除などの**状態遷移は、原則次のバー境界で適用**される。audio スレッド内で `global_sample >= target_bar_sample` になった瞬間に pending を current へ差し替える。デモ用途のため、バッファまたぎは**厳密なサンプル精度よりクリック等の事故防止（安全性）を優先**する（詳細は Risks #1）。
- **クロスフェード (XFade)**: ミキサー層の `xfade N` で N バーかけて A↔B をフェード。等パワーカーブ（`gainA=cos(θ)`, `gainB=sin(θ)`, θ=0..π/2）。フェードもバー境界で開始。
- **LLM ストリーム操作**: HTTP の SSE (`/events`) で状態を購読＋`PUT` 系で操作。加えて **MCP server（rmcp crate, stdio transport）**を `strudel-rs mcp` サブコマンドで起動し、Hermes からツール呼び出し可能にする。**MCP は本体 HTTP への薄いブリッジ**（演奏プロセスは手動起動。stdio 直結で audio を多重起動しない）。

**Tech Stack:** Rust stable / cpal / axum + tokio / rmcp（MCP）/ notify（ファイル監視）/ rustyline / crossbeam / serde+toml は使わず独自ミニパーサ（依存最小）。Linux ターゲット、依存システムライブラリは ALSA のみ。

**音源・エフェクトの位置づけ（重要）:**  
cpal は **音声デバイスへの入出力（コールバックで f32 バッファを埋める）だけ**を担当する。Strudel の Synths / Effects / Samples に相当する処理は **すべて自前 DSP**（`synth.rs` / サンプル再生 / `mixer.rs`）として audio コールバック内（またはその直前のレンダリング）で行う。WebAudio や SuperCollider は使わない。対応範囲の段階定義は後述 **「Strudel 音源・エフェクト対応方針（cpal 実装）」** を参照。参照ドキュメント: [Synths](https://strudel.cc/learn/synths/) / [Effects](https://strudel.cc/learn/effects/) / [Samples](https://strudel.cc/learn/samples/)。

## 可視化: Punchcard / Pianoroll（CLI 実現性調査）

参照: [Visual Feedback - Punchcard / Pianoroll](https://strudel.cc/learn/visual-feedback/)（スクリーンショット相当の機能）

### Strudel 本体がやっていること

| 関数 | 挙動 |
| --- | --- |
| `pianoroll` / `_pianoroll` | パターンを **その時点の評価結果** としてピアノロール風に描画 |
| `punchcard` / `_punchcard` | その後に付く変換（例: 後段の `.color`）も可視化に反映。ミニ記法ハイライトと同じイベント列を再利用するため **軽量** とされる |
| プレフィックス無し | ページ背景に描画 |
| `_` プレフィックス | コード行の直下（インライン）に描画。複数可 |

描画データは概ね:

- 横軸: 時間（cycles、既定 4 サイクル表示、playhead 位置など）
- 縦軸: ノート値（MIDI 相当、`minMidi`/`maxMidi`/`autorange`）
- 各イベント: 開始・長さ・音高・（任意）色・active/inactive
- オプション多数: `labels`, `vertical`, `flipTime`, `smear`, `fold`, active/inactive 色 など

音声 DSP とは独立した **イベント列の可視化** である（`_scope` / `_spectrum` のような波形解析とは別系統）。

### CLI / 本プロジェクトでの実現可否

**結論: 実現可能。** ただしブラウザ Canvas の見た目そのものではなく、**端末上の TUI（または簡易テキスト）近似**になる。

| 方式 | 実現性 | 見た目 | 備考 |
| --- | --- | --- | --- |
| **A. 端末 TUI**（ratatui + crossterm 等） | 高い | ブロック文字 + ANSI 色で矩形ノート | 推奨。Windows Terminal / 現代的 Linux 端末向け |
| B. プレーンテキストダンプ | 非常に高い | `█` や `#` の静止画・バー更新 | 依存ゼロ。デモ用最低限 |
| C. SVG/PNG 書き出し | 高い | ブラウザに近い | リアルタイム性が弱い。展示補助向き |
| D. 埋め込み WebView | 低い〜中 | 本物に近い | 依存・起動が重い。CLI 方針と乖離 |
| E. エディタ内インライン（`_punchcard`） | **不可に近い** | — | ブラウザ IDE 専用。外部エディタに差し込めない |

**「できそう」の根拠:**

1. **データは既にある** — Task 6 の `events(node, cycle)` と Deck のスケジュール結果（start/end/value/Hz）が、ロールのノート矩形そのもの
2. **Transport の playhead** — `bar_pos` / `global_sample` で縦線位置を更新できる
3. **描画負荷は軽い** — オシロ（scope）や FFT（spectrum）よりはるかに安い。audio スレッド外で「直近 N バーのイベント snapshot」を読めば足りる
4. **`.color("cyan")`** — パースしてメタに載せ、TUI の fg 色にマップすれば画像のデモに近い

**主な制約・設計論点:**

1. **REPL との端末競合** — rustyline とフルスクリーン TUI は同時に取り合いやすい  
   - 案1: `strudel-rs play --viz` で **画面分割**（上: ロール、下: 1 行コマンド or キーバインド操作）  
   - 案2: 別プロセス / 別端末で `strudel-rs viz` が HTTP SSE `/events` を購読して描画のみ  
   - 案3: ロールは **数 Hz で画面下部に差分更新**、REPL は通常どおり（ちらつきに注意）
2. **インライン `_punchcard()` は再現しない** — 曲ファイルでは `# viz: punchcard` や REPL `:viz on` / トラック単位フラグで代替
3. **pianoroll vs punchcard の差** — 初期は「Engine が実際に鳴らす最終イベント列」を描く（＝演奏と一致 = punchcard 寄り）。中間パターン専用の pianoroll は後回しで可
4. **解像度** — 端末の行列数に合わせて縦（音域）を fold/autorange。細かい半音は行が足りないと潰れる → `autorange` + アクティブ音域のみ表示が実用的
5. **ステレオ/パンや jux の視覚** — 初期非対応でよい（ノート矩形のみ）

### 推奨スコープ（Task 25）

## Strudel 音源・エフェクト対応方針（cpal 実装）

参照（公式）:

- Synths: https://strudel.cc/learn/synths/
- Effects: https://strudel.cc/learn/effects/
- Samples: https://strudel.cc/learn/samples/

### cpal の役割（誤解防止）

| 層 | 担当 | 実装場所の目安 |
| --- | --- | --- |
| **I/O** | デバイスオープン、サンプルレート、コールバックで `&mut [f32]` を埋める | `backend.rs` + cpal |
| **時計** | BPM・バー・global_sample | `transport.rs` |
| **パターン→イベント** | mini 記法評価、メソッドチェーン | `mini.rs` / `code.rs` |
| **音源** | オシレータ / ノイズ / サンプル再生 | `synth.rs` / `sample.rs` |
| **パーボイス FX** | ADSR, lpf/hpf, gain, speed 等（イベントごと） | Voice 内 |
| **バス FX / 切替** | A/B フェーダー, EQ, xfade（必要なら delay/room） | `mixer.rs` |
| **テスト** | デバイス無しで同じ DSP を回す | `NullBackend` |

**Strudel 本体はブラウザの WebAudio グラフ。** 本プロジェクトは同等のグラフを Rust で薄いサブセットとして実装し、最終ミックスだけ cpal に渡す。cpal にシンセ API はない。

デモ用途のため **Strudel 全機能の再実装は目標にしない。** 以下のティアで切り、Task 1–22 は主に **ティアA** を満たせば完了とする。

### Sound 名の解決（Risks #2 確定）

Strudel では `s` / `sound` が **サンプルとシンセの両方**を指す（言語面は共通、エンジンは別）。

本実装の解決順:

```
resolve_sound(name):
  1. 固定波形リストに name がある → Synth(Wave|Noise)
  2. SampleBank に name がある     → Sample(name)
  3. どちらも無い                 → Error（"unknown sound: {name}"。波形でもサンプルでもない、と明示）
```

- **波形優先**（リストが短いため衝突 practically ほぼ無し）
- `note("c3").s("bd")` はサンプルを **音程付き**で再生可能（基準ピッチはサンプル側デフォルト C またはメタデータ。初期は「A4=440 相対で speed 換算」など単純ルールで可）
- `s("bd sd")` は各イベント値が sound 名 → 同じ `resolve_sound`
- タイポ時は「波形リストに無くサンプルにも無い」を一文で返す

初期波形リスト（ティアA）:

`sine`, `sawtooth`/`saw`, `square`, `triangle`/`tri`, およびノイズ `white`, `pink`, `brown`（Strudel [Synths](https://strudel.cc/learn/synths/) の Basic Waveforms + Noise の最小セット）

### Synths — Strudel 機能と実装方針

出典: [strudel.cc/learn/synths](https://strudel.cc/learn/synths/)

| Strudel 機能 | 概要 | ティア | cpal 側の実装メモ |
| --- | --- | --- | --- |
| Basic waveforms | sine / sawtooth / square / triangle | **A** | 位相累積オシレータ。audio スレッドで `phase += freq/sr`。アンチエイリアスはデモではナイーブで可（必要なら後で polyBLEP） |
| デフォルト sound | note のみのとき triangle | **A** | `PatternCode.sound` デフォルト `"triangle"` |
| Noise white/pink/brown | ノイズ音源 | **A** | white=一様乱数、pink/brown は簡易フィルタ（Paul Kellet 等の短い IIR で十分） |
| `noise` パラメータ | オシレータにピンクノイズ混入 | B | Voice に mix 係数 |
| `crackle` + density | クラックル | C / 非対応可 | 優先度低 |
| `partials` / `phases` / `user` | 加算合成 | C | コスト高。デモ非必須 |
| `vib` / `vibmod` | ビブラート | **B** | `freq *= 2^(semitone*sin(2π·f_vib·t)/12)` |
| FM (`fm`, `fmh`, envelope) | FM 合成 | **B** | 簡易 1 オペレータ: `car = sin(2π·(fc+fm_idx·sin(2π·fmh·fc·t))·t)`。フル 8op はしない |
| Wavetable `wt_*` | 1 周期波形ループ | C | サンプル loop の特殊ケースとして後付け可 |
| ZZFX `z_*` | ゲーム向けシンセ | **非対応** | 別エンジン。パースで未知 sound として落とす |

**ティアA の Voice 信号（1 サンプル）概略:**

```
osc/noise →（optional 簡易 FM/vib は B）→ amp ADSR → gain
         → one-pole or biquad LPF（.lpf）→ ボイス出力
```

ADSR は Strudel [Effects - Amplitude Envelope](https://strudel.cc/learn/effects/) の `attack`/`decay`/`sustain`/`release`（および `.adsr("a:d:s:r")`）をティアAでサポートする。現状プランの「短いアタック + 末尾リリース」は仮実装であり、Task 8 で正規 ADSR に寄せる。

### Effects — シグナルチェーンと配置

出典: [strudel.cc/learn/effects](https://strudel.cc/learn/effects/)（公式のローカル FX 順序・orbit の説明）

Strudel の概念:

- **Local effects:** イベント（ボイス）ごとに独立チェーン。同じメソッドを二度書いても **上書き**（直列の二段 lpf にはならない）
- **Global effects:** orbit 単位で共有（delay / room など）。パラメータの取り合いに注意

本プロジェクトへの写像:

```
[Deck A tracks] → voices (local FX) ─┐
                                     ├→ Mixer: gain_a/b, channel EQ/filter, xfade → cpal
[Deck B tracks] → voices (local FX) ─┘
```

| Strudel FX | 種別 | ティア | 実装メモ（Rust/cpal） |
| --- | --- | --- | --- |

**パーボイス vs ミキサーの切り分け（確定方針）:**

- **曲・トラック由来**の `.lpf` `.gain` `.adsr` 等 → Voice（local）
- **演奏操作由来**の A/B 音量・チャンネル EQ・曲切替 xfade → Mixer

### リアルタイム制約（全ティア共通）

audio コールバック（cpal）内:

- **アロケーション禁止**（Vec の push で伸びる処理を毎バッファやらない）。Voice はプール

- クリップ防止: ミックス後 `tanh` または soft clip。`|x|<=1` を E2E で監視

```rust
/// 共有時計。両デッキが同じ global_sample を参照するので同期が保証される。
/// 1 bar = 4 beats。BPM 120 → 1 bar = 2.0s。
pub struct Transport {
    pub sample_rate: u32,
    pub bpm: f64,
    pub global_sample: u64,
}

impl Transport {
    pub fn new(sample_rate: u32, bpm: f64) -> Self {
        Self { sample_rate, bpm, global_sample: 0 }
    }
    pub fn samples_per_beat(&self) -> f64 { self.sample_rate as f64 * 60.0 / self.bpm }
    pub fn samples_per_bar(&self) -> f64 { self.samples_per_beat() * 4.0 }
    /// 現在のバー番号
    pub fn bar_index(&self) -> u64 {
        (self.global_sample as f64 / self.samples_per_bar()) as u64
    }
    /// バー内位置 [0,1)
    pub fn bar_pos(&self) -> f64 {
        (self.global_sample as f64 % self.samples_per_bar()) / self.samples_per_bar()
    }
    /// n バー先のバー頭の絶対サンプル位置 (n=1 で次のバー頭)
    pub fn bar_boundary(&self, n: u64) -> u64 {
        ((self.bar_index() + n) as f64 * self.samples_per_bar()) as u64
    }
    pub fn advance(&mut self, frames: usize) { self.global_sample += frames as u64; }
    pub fn set_bpm(&mut self, bpm: f64) { self.bpm = bpm; }
}

#[cfg(test)]
mod tests {

    #[test]
    fn bar_math() {
```

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum Token {
    Word(String),
    Rest,                          // ~
    OpenBracket, CloseBracket,     // [ ]
    OpenAngle, CloseAngle,         // < >
    Star, Slash,                   // * /
    Number(f64),
}

pub fn tokenize(input: &str) -> Result<Vec<Token>, String> {
    let mut out = Vec::new();
    let mut chars = input.chars().peekable();
    while let Some(&c) = chars.peek() {
        match c {
            ' ' | '\t' | '\n' | ',' => { chars.next(); }
            '~' => { out.push(Token::Rest); chars.next(); }
            '[' => { out.push(Token::OpenBracket); chars.next(); }
            ']' => { out.push(Token::CloseBracket); chars.next(); }
            '<' => { out.push(Token::OpenAngle); chars.next(); }
            '>' => { out.push(Token::CloseAngle); chars.next(); }
            '*' => { out.push(Token::Star); chars.next(); }
            '/' => { out.push(Token::Slash); chars.next(); }
            c if c.is_ascii_alphanumeric() || matches!(c, '.' | '#' | '-' | '_') => {
                let mut w = String::new();
                while let Some(&c) = chars.peek() {
                    if c.is_ascii_alphanumeric() || matches!(c, '.' | '#' | '-' | '_') {
                        w.push(c); chars.next();
                    } else { break; }
                }
                if let Ok(n) = w.parse::<f64>() { out.push(Token::Number(n)); }
                else { out.push(Token::Word(w)); }
            }
            other => return Err(format!("unexpected char: {other}")),
        }
    }
    Ok(out)
}
```

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum Node {
    Atom(String),
    Rest,
    Seq(Vec<Node>),        // [a b] / トップレベル: 1サイクル等分
    Stack(Vec<Node>),      // <a b>: サイクルごとに1つ選択
    Fast(Box<Node>, f64),  // node * n
    Slow(Box<Node>, f64),  // node / n
}

pub fn parse(input: &str) -> Result<Node, String> {
    let toks = tokenize(input)?;
    if toks.is_empty() { return Ok(Node::Rest); }
    let mut pos = 0;
    let node = parse_seq(&toks, &mut pos, None)?;
    if pos != toks.len() { return Err(format!("trailing tokens at {pos}")); }
    Ok(node)
}

fn parse_seq(t: &[Token], pos: &mut usize, closing: Option<Token>) -> Result<Node, String> {
    let mut items = Vec::new();
    while *pos < t.len() {
        if Some(&t[*pos]) == closing.as_ref() { *pos += 1; break; }
        let mut item = parse_item(t, pos)?;
        loop {
            if *pos + 1 < t.len() && matches!(t[*pos], Token::Star) {
                if let Token::Number(n) = t[*pos + 1] {
                    item = Node::Fast(Box::new(item), n); *pos += 2; continue;
                }
            }
            if *pos + 1 < t.len() && matches!(t[*pos], Token::Slash) {
                if let Token::Number(n) = t[*pos + 1] {
                    item = Node::Slow(Box::new(item), n); *pos += 2; continue;
                }
            }
            break;
        }
        items.push(item);
    }
    Ok(Node::Seq(items))
}

fn parse_item(t: &[Token], pos: &mut usize) -> Result<Node, String> {
    match t.get(*pos) {
        Some(Token::Word(w)) => { *pos += 1; Ok(Node::Atom(w.clone())) }
        Some(Token::Rest) => { *pos += 1; Ok(Node::Rest) }
        Some(Token::Number(n)) => { *pos += 1; Ok(Node::Atom(n.to_string())) }
        Some(Token::OpenBracket) => { *pos += 1; parse_seq(t, pos, Some(Token::CloseBracket)) }
        Some(Token::OpenAngle) => {
            *pos += 1;
            let s = parse_seq(t, pos, Some(Token::CloseAngle))?;
            if let Node::Seq(v) = s { Ok(Node::Stack(v)) } else { unreachable!() }
        }
        other => Err(format!("unexpected token: {other:?}")),
    }
}
```

### Task 6: パターン評価器

**Objective:** AST + サイクル番号 → 時刻付きイベント列。1 サイクル = 1 バー。

**Files:**

```rust
#[derive(Debug, Clone, PartialEq)]
pub struct Event {
    pub start: f64,   // サイクル(=バー)内位置 [0,1)
    pub dur: f64,     // バー単位の長さ
    pub value: String,
}

pub fn events(node: &Node, cycle: u64) -> Vec<Event> {
    let mut out = Vec::new();
    emit(node, 0.0, 1.0, cycle, &mut out);
    out
}

fn emit(node: &Node, start: f64, span: f64, cycle: u64, out: &mut Vec<Event>) {
    match node {
        Node::Atom(v) => out.push(Event { start, dur: span, value: v.clone() }),
        Node::Rest => {}
        Node::Seq(items) => {
            if items.is_empty() { return; }
            let each = span / items.len() as f64;
            for (i, it) in items.iter().enumerate() {
                emit(it, start + i as f64 * each, each, cycle, out);
            }
        }
        Node::Stack(items) => {
            if items.is_empty() { return; }
            let sel = (cycle as usize) % items.len();
            emit(&items[sel], start, span, cycle, out);
        }
        Node::Fast(inner, n) => {
            let sub = span / n;
            for k in 0..(*n as usize) {
                emit(inner, start + k as f64 * sub, sub, cycle, out);
            }
        }
        Node::Slow(inner, n) => {
            if cycle % (*n as u64) == 0 { emit(inner, start, span, cycle, out); }
        }
    }
}
```

**Objective:** メソッドチェーンをパースし、音名→Hz に加え **和音記法（`c3'maj` 等）を構成音へ展開**する（Risks #3 確定）。

**Step 1: コード**

```rust
use crate::mini::{self, Node};

#[derive(Debug, Clone)]
pub struct PatternCode {
    pub pattern: Node,
    pub sound: String,        // "sawtooth" または "bd" 等のサンプル名
    pub gain: f32,
    pub lpf: Option<f32>,
    pub speed: f64,           // slow/fast の積算
    pub is_note: bool,        // note()/n() なら音名→Hz
    pub raw: String,          // 表示用の元コード
}

pub fn parse_code(input: &str) -> Result<PatternCode, String> {
    let mut pc = PatternCode {
        pattern: Node::Rest, sound: "sine".into(), gain: 0.5,
        lpf: None, speed: 1.0, is_note: false, raw: input.trim().to_string(),
    };
    let input = input.trim();
    let open = input.find('(').ok_or("missing (")?;
    let head = input[..open].trim();
    if !matches!(head, "note" | "n" | "s" | "sound") {
        return Err(format!("unknown head: {head} (use note/s)"));
    }
    let first_str = extract_first_string(&input[open..])?;
    pc.pattern = mini::parse(&first_str)?;
    pc.is_note = matches!(head, "note" | "n");
    if matches!(head, "s" | "sound") { pc.sound = first_word(&first_str); }

    // .name(args) チェーン走査
    let mut cur = &input[open..];
    while let Some(dot) = cur.find('.') {
        let after = &cur[dot + 1..];
        let paren = after.find('(').ok_or("missing ( in method")?;
        let name = after[..paren].trim();
        let mut depth = 0i32; let mut end = paren;
        for (i, ch) in after[paren..].char_indices() {
            match ch {
                '(' => depth += 1,
                ')' => { depth -= 1; if depth == 0 { end = paren + i; break; } }
                _ => {}
            }
        }
        if depth != 0 { return Err("unbalanced parens".into()); }
        let args = &after[paren + 1..end];
        apply_method(&mut pc, name, args)?;
        cur = &after[end + 1..];
    }
    Ok(pc)
}

fn first_word(s: &str) -> String {
    s.split_whitespace().next().unwrap_or("sine").to_string()
}

fn extract_first_string(s: &str) -> Result<String, String> {
    let start = s.find('"').ok_or("missing \"")?;
    let end = s[start + 1..].find('"').ok_or("missing closing \"")? + start + 1;
    Ok(s[start + 1..end].to_string())
}

fn apply_method(pc: &mut PatternCode, name: &str, args: &str) -> Result<(), String> {
    let num = |a: &str| a.trim().trim_matches('"').parse::<f64>()
        .map_err(|_| format!("bad number: {a}"));
    match name {
        // sound 名は文字列保持のみ。再生時に resolve_sound（波形リスト → サンプル）
        "s" | "sound" => { pc.sound = args.trim().trim_matches('"').to_string(); Ok(()) }
        "gain" => { pc.gain = num(args)? as f32; Ok(()) }
        "velocity" | "vel" => Ok(()), // gain に乗算するフィールドへ
        "lpf" | "cutoff" | "lp" | "ctf" => { pc.lpf = Some(num(args)? as f32); Ok(()) }
        "attack" | "att" | "decay" | "dec" | "sustain" | "sus" | "release" | "rel" | "adsr" => {
            Ok(()) // PatternCode に ADSR を持たせ Task 8 で Voice へ
        }
        "begin" | "end" | "speed" => Ok(()), // サンプル再生（Task 9）
        "slow" => { pc.speed /= num(args)?; Ok(()) }
        "fast" => { pc.speed *= num(args)?; Ok(()) }
        "note" | "n" => Ok(()), // n がサンプル index の文脈は Deck 側で解釈
        other => Err(format!("unsupported method: {other}")),
    }
}

/// 単音名 → Hz。和音トークンは expand_chord 経由で使う。
pub fn note_to_hz(note: &str) -> Result<f32, String> {
    let (name, oct) = note.split_at(note.len().saturating_sub(1));
    let oct: i32 = oct.parse().map_err(|_| format!("bad octave in {note}"))?;
    let semis = match name.to_ascii_lowercase().as_str() {
        "c" => 0, "c#" | "db" => 1, "d" => 2, "d#" | "eb" => 3, "e" => 4, "f" => 5,
        "f#" | "gb" => 6, "g" => 7, "g#" | "ab" => 8, "a" => 9, "a#" | "bb" => 10, "b" => 11,
        other => return Err(format!("bad note: {other}")),
    };
    let midi = (oct + 1) * 12 + semis;
    Ok(440.0 * 2f32.powf((midi - 69) as f32 / 12.0))
}
```

```rust
#[derive(Clone, Copy, PartialEq, Debug)]
pub enum Wave { Sine, Saw, Square, Triangle }

impl Wave {
    pub fn from_str(s: &str) -> Option<Self> {
        match s {
            "sine" => Some(Wave::Sine),
            "sawtooth" | "saw" => Some(Wave::Saw),
            "square" => Some(Wave::Square),
            "triangle" | "tri" => Some(Wave::Triangle),
            _ => None,   // サンプル名の可能性
        }
    }
    fn sample(&self, phase: f32) -> f32 {
        match self {
            Wave::Sine => (phase * 2.0 * std::f32::consts::PI).sin(),
            Wave::Saw => 2.0 * phase - 1.0,
            Wave::Square => if phase < 0.5 { 1.0 } else { -1.0 },
            Wave::Triangle => 4.0 * (phase - 0.5).abs() - 1.0,
        }
    }
}

pub struct Voice {
    pub wave: Wave,
    pub freq: f32,
    pub gain: f32,
    phase: f32,
    pos: u64,
    len: u64,
    lpf: Option<f32>,
    lpf_y: f32,
}

impl Voice {
    pub fn new(wave: Wave, freq: f32, gain: f32, len: u64, lpf: Option<f32>) -> Self {
        Self { wave, freq, gain, phase: 0.0, pos: 0, len, lpf, lpf_y: 0.0 }
    }
    pub fn next_sample(&mut self, sr: f32) -> Option<f32> {
        if self.pos >= self.len { return None; }
        let a = (0.005 * sr) as u64;
        let r = ((self.len as f32 * 0.2) as u64).max(1);
        let env = if self.pos < a { self.pos as f32 / a as f32 }
                  else if self.pos > self.len.saturating_sub(r) {
                      (self.len - self.pos) as f32 / r as f32
                  } else { 1.0 };
        let mut x = self.wave.sample(self.phase) * env * self.gain;
        self.phase = (self.phase + self.freq / sr) % 1.0;
        self.pos += 1;
        if let Some(cut) = self.lpf {
            let k = 1.0 - (-2.0 * std::f32::consts::PI * cut / sr).exp();
            self.lpf_y += k * (x - self.lpf_y);
            x = self.lpf_y;
        }
        Some(x)
    }
}
```

```rust
use std::collections::HashMap;
use std::path::Path;

/// 16bit PCM mono WAV のみ対応（ローダを最小化するため）。
/// 44.1kHz 以外は線形補間で再生側がピッチシフトする形を取らず、
/// ロード時に 48000Hz へ最近傍リサンプルする。
pub struct SampleBank {
    samples: HashMap<String, Vec<f32>>,
}

impl SampleBank {
    pub fn load_dir(dir: &Path, target_sr: u32) -> Self {
        let mut samples = HashMap::new();
        if let Ok(rd) = std::fs::read_dir(dir) {
            for e in rd.flatten() {
                let p = e.path();
                if p.extension().and_then(|s| s.to_str()) == Some("wav") {
                    if let Ok(data) = load_wav(&p, target_sr) {
                        let name = p.file_stem().unwrap().to_string_lossy().to_string();
                        samples.insert(name, data);
                    }
                }
            }
        }
        Self { samples }
    }
    pub fn get(&self, name: &str) -> Option<&Vec<f32>> { self.samples.get(name) }
    pub fn names(&self) -> Vec<String> { self.samples.keys().cloned().collect() }
}

fn load_wav(path: &Path, target_sr: u32) -> Result<Vec<f32>, String> {
    let bytes = std::fs::read(path).map_err(|e| e.to_string())?;
    if bytes.len() < 44 || &bytes[0..4] != b"RIFF" { return Err("not wav".into()); }
    let channels = u16::from_le_bytes([bytes[22], bytes[23]]) as usize;
    let src_sr = u32::from_le_bytes([bytes[24], bytes[25], bytes[26], bytes[27]]);
    let bits = u16::from_le_bytes([bytes[34], bytes[35]]);
    if bits != 16 { return Err("only 16bit wav".into()); }
    // data チャンク探索
    let mut i = 12;
    let data = loop {
        if i + 8 > bytes.len() { return Err("no data chunk".into()); }
        let id = &bytes[i..i + 4];
        let size = u32::from_le_bytes([bytes[i+4], bytes[i+5], bytes[i+6], bytes[i+7]]) as usize;
        if id == b"data" { break &bytes[i + 8..(i + 8 + size).min(bytes.len())]; }
        i += 8 + size + (size % 2);
    };
    // 16bit → f32、多ch は先頭 ch のみ
    let mut out: Vec<f32> = data.chunks_exact(2 * channels)
        .map(|c| i16::from_le_bytes([c[0], c[1]]) as f32 / 32768.0)
        .collect();
    // リサンプル（最近傍）
    if src_sr != target_sr && !out.is_empty() {
        let ratio = src_sr as f64 / target_sr as f64;
        let n = (out.len() as f64 / ratio) as usize;
        out = (0..n).map(|k| out[(k as f64 * ratio) as usize % out.len()]).collect();
    }
    Ok(out)
}
```

```rust
#[derive(Debug, Clone)]

}

#[derive(Debug, Clone)]
pub struct Song {

    pub tracks: Vec<Track>,

/// フォーマット:
///   // コメント
///   bpm: 126
///   title: My Song        (省略可, 省略時はファイル名)
///   ---
///   kick: s("bd*4").gain(0.9)
///   bass: note("c2 eb2 g2").s("sawtooth").lpf(400)
pub fn parse_song(text: &str, path: &str) -> Result<Song, String> {
    let mut bpm = None;
    let mut title: Option<String> = None;
    let mut tracks = Vec::new();
    let mut in_header = true;

    for (lineno, line) in text.lines().enumerate() {
        let line = line.trim();
        if line.is_empty() || line.starts_with("//") || line.starts_with('#') { continue; }
        if in_header {
            if line == "---" { in_header = false; continue; }
            if let Some(v) = line.strip_prefix("bpm:") {
                bpm = Some(v.trim().parse().map_err(|_| format!("line {}: bad bpm", lineno + 1))?);
                continue;
            }
            if let Some(v) = line.strip_prefix("title:") {
                title = Some(v.trim().to_string());
                continue;
            }
            // ヘッダ以外の行が来たらトラック開始とみなす（--- 省略可）
            in_header = false;
        }
        let (name, code_str) = line.split_once(':')
            .ok_or_else(|| format!("line {}: expected 'name: code'", lineno + 1))?;
        let name = name.trim().to_string();
        if name.is_empty() { return Err(format!("line {}: empty track name", lineno + 1)); }
        let code = parse_code(code_str.trim())
            .map_err(|e| format!("line {} ({}): {}", lineno + 1, name, e))?;
        tracks.push(Track { name, code, muted: false });
    }
    if tracks.is_empty() { return Err("no tracks".into()); }
    Ok(Song {
        title: title.unwrap_or_else(|| path.rsplit('/').next().unwrap_or(path).to_string()),
        bpm, tracks, path: path.to_string(),
    })
}
```

**Objective:** 1 デッキ = Song の全トラックを鳴らすユニット。ボイスプール + デッキゲイン（フェード用）。

**Files:**

**Step 1: コード**

```rust
use crate::code::note_to_hz;
use crate::mini;
use crate::sample::SampleBank;
use crate::song::Song;
use crate::synth::{SampleVoice, SynthVoice, VoiceKind, Wave};
use crate::transport::Transport;

pub const MAX_VOICES: usize = 32;

/// 1イベント分の発音指示
struct ScheduledHit {
    at_sample: u64,
    len_samples: u64,
    sound: String,
    freq: f32,
    gain: f32,
    lpf: Option<f32>,
}

pub struct Deck {
    pub name: String,           // "A" / "B"
    song: Option<Song>,
    pub gain: f32,              // クロスフェード用 0..1
    voices: Vec<Option<VoiceKind>>,
    scheduled: Vec<ScheduledHit>,
    next_event: usize,
    scheduled_bar: u64,
}

impl Deck {
    pub fn new(name: &str) -> Self {
        Self {
            name: name.to_string(), song: None, gain: 1.0,
            voices: vec![None; MAX_VOICES],
            scheduled: Vec::with_capacity(512),
            next_event: 0, scheduled_bar: u64::MAX,
        }
    }

    pub fn load(&mut self, song: Song) {
        self.song = Some(song);
        self.scheduled_bar = u64::MAX;   // 強制再スケジュール
    }
    pub fn unload(&mut self) {
        self.song = None;
        self.voices.iter_mut().for_each(|v| *v = None);
    }
    pub fn song_title(&self) -> Option<&str> { self.song.as_ref().map(|s| s.title.as_str()) }

    /// 指定バーのイベントを前計算（1 bar = 1 cycle）
    fn schedule_bar(&mut self, bar: u64, transport: &Transport) {
        self.scheduled.clear();
        self.next_event = 0;
        if let Some(song) = &self.song {
            let spb = transport.samples_per_bar();
            let bar_start = (bar as f64 * spb) as u64;
            for track in &song.tracks {
                if track.muted { continue; }
                let pc = &track.code;
                for ev in mini::events(&pc.pattern, bar) {
                    let at = bar_start + (ev.start * spb / pc.speed.max(1e-6)) as u64;
                    let len = ((ev.dur * spb / pc.speed.max(1e-6)) as u64).max(64);
                    let freq = if pc.is_note {
                        match note_to_hz(&ev.value) { Ok(h) => h, Err(_) => continue }
                    } else { 0.0 };
                    self.scheduled.push(ScheduledHit {
                        at_sample: at, len_samples: len,
                        sound: if pc.is_note { pc.sound.clone() } else { ev.value.clone() },
                        freq, gain: pc.gain, lpf: pc.lpf,
                    });
                }
            }
            self.scheduled.sort_by_key(|e| e.at_sample);
        }
        self.scheduled_bar = bar;
    }

    /// オーディオコールバック本体。samples バンクは発音時に参照。
    pub fn process(&mut self, out: &mut [f32], transport: &Transport, samples: &SampleBank) {
        let sr = transport.sample_rate as f32;
        let bar = transport.bar_index();
        if bar != self.scheduled_bar { self.schedule_bar(bar, transport); }

        for (i, frame) in out.iter_mut().enumerate() {
            let now = transport.global_sample + i as u64;
            while self.next_event < self.scheduled.len()
                && self.scheduled[self.next_event].at_sample <= now
            {
                let hit = &self.scheduled[self.next_event];
                self.next_event += 1;
                if let Some(slot) = self.voices.iter_mut().find(|v| v.is_none()) {
                    *slot = if let Some(wave) = Wave::from_str(&hit.sound) {
                        Some(VoiceKind::Synth(SynthVoice::new(wave, hit.freq, hit.gain, hit.len_samples, hit.lpf)))
                    } else if let Some(data) = samples.get(&hit.sound) {
                        Some(VoiceKind::Sample(SampleVoice::new(
                            std::sync::Arc::new(data.clone()), hit.gain)))
                    } else {
                        None   // 未知の音名/サンプル名は捨てる
                    };
                }
            }
            let mut mix = 0f32;
            for v in self.voices.iter_mut() {
                if let Some(voice) = v {
                    let s = match voice {
                        VoiceKind::Synth(sv) => sv.next_sample(sr),
                        VoiceKind::Sample(pv) => pv.next_sample(),
                    };
                    match s { Some(x) => mix += x, None => *v = None }
                }
            }
            *frame = mix * self.gain;
        }
    }
}
```

### Task 12: Engine 統合（Command + バー境界 pending 適用）

**Objective:** 全入力を Command として受け、バー境界で遷移を適用する中核。まず単一デッキで完結させる。

**Files:**
- Create: `strudel-rs/src/engine.rs`

**Step 1: コード**

```rust
use crate::deck::Deck;
use crate::sample::SampleBank;
use crate::song::Song;
use crate::transport::Transport;

pub enum Command {
    LoadSong { deck: usize, song: Song },        // バー境界で適用
    UnloadDeck { deck: usize },
    SetBpm(f64),                                  // 次バー頭から適用
    Hush,                                         // 即時（全デッキ unload）
    XFade { to_deck: usize, bars: u32 },          // 次バー頭から bars バーかけてフェード
    SetTrackMute { deck: usize, track: String, muted: bool }, // 次バー頭から
}

/// バー境界で適用待ちの遷移
enum Pending {
    LoadSong { deck: usize, song: Song },
    SetBpm(f64),
    XFade { to_deck: usize, bars: u32 },
    TrackMute { deck: usize, track: String, muted: bool },
}

pub struct Engine {
    pub transport: Transport,
    pub decks: [Deck; 2],
    pending: Vec<Pending>,
    xfade: Option<XFadeState>,
}

struct XFadeState {
    to_deck: usize,
    start_sample: u64,
    end_sample: u64,
}

impl Engine {
    pub fn new(sample_rate: u32, bpm: f64) -> Self {
        Self {
            transport: Transport::new(sample_rate, bpm),
            decks: [Deck::new("A"), Deck::new("B")],
            pending: Vec::new(),
            xfade: None,
        }
    }

    pub fn push_command(&mut self, cmd: Command) {
        match cmd {
            Command::Hush => {                       // hush だけ即時
                self.decks[0].unload();
                self.decks[1].unload();
                self.xfade = None;
            }
            Command::UnloadDeck { deck } => self.decks[deck].unload(),
            Command::LoadSong { deck, song } => self.pending.push(Pending::LoadSong { deck, song }),
            Command::SetBpm(b) => self.pending.push(Pending::SetBpm(b)),
            Command::XFade { to_deck, bars } => self.pending.push(Pending::XFade { to_deck, bars }),
            Command::SetTrackMute { deck, track, muted } =>
                self.pending.push(Pending::TrackMute { deck, track, muted }),
        }
    }

    /// バー境界をまたいだか判定し、pending を適用する。
    /// audio バッファ処理の先頭で呼ぶ（厳密にはバッファ内で境界をまたぐ場合も
    /// バッファ先頭で適用する。バッファ 256 samples ≒ 5ms なので体感問題なし）。
    fn apply_pending_at_bar_boundary(&mut self) {
        let bar_now = self.transport.bar_index();
        // 前回呼び出し時とバーが変わっていたら境界通過
        // （engine は last_bar を内部保持）
        if self.last_bar() == bar_now { return; }
        self.set_last_bar(bar_now);

        let pending = std::mem::take(&mut self.pending);
        for p in pending {
            match p {
                Pending::LoadSong { deck, song } => self.decks[deck].load(song),
                Pending::SetBpm(b) => self.transport.set_bpm(b),
                Pending::TrackMute { deck, track, muted } => {
                    if let Some(song) = self.decks[deck].song_mut() {
                        for t in &mut song.tracks {
                            if t.name == track { t.muted = muted; }
                        }
                    }
                }
                Pending::XFade { to_deck, bars } => {
                    let start = self.transport.global_sample;
                    let len = (bars as f64 * self.transport.samples_per_bar()) as u64;
                    self.xfade = Some(XFadeState { to_deck, start_sample: start, end_sample: start + len });
                }
            }
        }
    }

    // last_bar の保持（簡潔さのためフィールドとして定義すること。実装時に追加）
    fn last_bar(&self) -> u64 { self.last_bar }
    fn set_last_bar(&mut self, b: u64) { self.last_bar = b; }

    pub fn process(&mut self, out: &mut [f32], samples: &SampleBank) {
        self.apply_pending_at_bar_boundary();

        // クロスフェードゲイン計算（バッファ先頭の値で代表）
        if let Some(x) = &self.xfade {
            let t = ((self.transport.global_sample.saturating_sub(x.start_sample)) as f64
                / (x.end_sample - x.start_sample) as f64).clamp(0.0, 1.0);
            let theta = t * std::f64::consts::FRAC_PI_2;
            let (from, to) = if x.to_deck == 1 { (0, 1) } else { (1, 0) };
            self.decks[from].gain = theta.cos() as f32;
            self.decks[to].gain = theta.sin() as f32;
            if t >= 1.0 {
                self.decks[from].unload();   // フェード完了で旧デッキ停止
                self.decks[from].gain = 0.0;
                self.decks[to].gain = 1.0;
                self.xfade = None;
            }
        }

        let mut a = vec![0f32; out.len()];
        let mut b = vec![0f32; out.len()];
        self.decks[0].process(&mut a, &self.transport, samples);
        self.decks[1].process(&mut b, &self.transport, samples);
        for i in 0..out.len() { out[i] = (a[i] + b[i]).clamp(-1.0, 1.0); }
        self.transport.advance(out.len());
    }
}
```

```rust
use crate::engine::Command;
use crate::song::parse_song;
use crossbeam::channel::Sender;
use notify::{RecommendedWatcher, RecursiveMode, Watcher};
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex};

/// 監視対象: パス → どのデッキにロードされているか
pub type DeckPaths = Arc<Mutex<[Option<PathBuf>; 2]>>;

pub fn watch_songs(
    dir: &Path,
    tx: Sender<Command>,
    deck_paths: DeckPaths,
) -> notify::Result<RecommendedWatcher> {
    let mut watcher = notify::recommended_watcher(move |res: notify::Result<notify::Event>| {
        let Ok(ev) = res else { return };
        if !matches!(ev.kind, notify::EventKind::Modify(_) | notify::EventKind::Create(_)) {
            return;
        }
        for path in ev.paths {
            if path.extension().and_then(|s| s.to_str()) != Some("strudel") { continue; }
            let deck = {
                let dp = deck_paths.lock().unwrap();
                dp.iter().position(|p| p.as_ref() == Some(&path))
            };
            let Some(deck) = deck else { continue };  // ロードされていないファイルは無視
            match std::fs::read_to_string(&path) {
                Ok(text) => match parse_song(&text, &path.to_string_lossy()) {
                    Ok(song) => {
                        println!("↻ {} → deck {} (次の小節から反映)", song.title, deck);
                        tx.send(Command::LoadSong { deck, song }).ok();
                    }
                    Err(e) => eprintln!("⚠ {}: parse error (現行の曲を継続): {e}", path.display()),
                },
                Err(e) => eprintln!("⚠ read error: {e}"),
            }
        }
    })?;
    watcher.watch(dir, RecursiveMode::NonRecursive)?;
    Ok(watcher)
}
```

```rust
use crate::engine::Command;
use crate::song::parse_song;
use crossbeam::channel::Sender;
use rustyline::DefaultEditor;
use std::path::PathBuf;
use crate::watcher::DeckPaths;

pub fn run(tx: Sender<Command>, deck_paths: DeckPaths) {
    let mut rl = DefaultEditor::new().unwrap();
    println!(r#"strudel-rs
  :load <A|B> <file.strudel>   曲をデッキにロード（次の小節から）
  :xfade <A|B> [bars=4]        N小節かけてデッキ切替

                let args: Vec<&str> = line.split_whitespace().collect();

                                Ok(song) => {
                                    deck_paths.lock().unwrap()[deck] = Some(path);
                                    tx.send(Command::LoadSong { deck, song }).ok();
                                    println!("loaded (次の小節から)");
                                }
                                Err(e) => eprintln!("parse error: {e}"),
                            },
                            Err(e) => eprintln!("read error: {e}"),
                        }
                    }
                    ":xfade" if args.len() >= 2 => {
                        let to = match args[1] { "A" | "a" => 0, "B" | "b" => 1, _ => continue };
                        let bars = args.get(2).and_then(|s| s.parse().ok()).unwrap_or(4);
                        tx.send(Command::XFade { to_deck: to, bars }).ok();
                        println!("xfade → {} ({} bars, 次の小節から)", args[1], bars);
                    }
                    ":mute" | ":unmute" if args.len() == 3 => {
                        let deck = match args[1] { "A" | "a" => 0, "B" | "b" => 1, _ => continue };

                            deck, track: args[2].to_string(),
                            muted: args[0] == ":mute",
                        }).ok();
                    }
                    ":status" => {
                        let dp = deck_paths.lock().unwrap();
                        println!("deck A: {:?} / deck B: {:?}", dp[0], dp[1]);
                    }
                    _ => eprintln!("unknown command"),
                }
            }
            Err(_) => break,
        }
    }
}
```

```rust
    s.tx.send(Command::SetTrackMute {
        deck: deck_idx(&r.deck)?, track: r.track, muted: r.muted,
    }).map_err(|e| bad(e.to_string()))?;
    Ok(StatusCode::ACCEPTED)
}

async fn hush(State(s): State<AppState>) -> StatusCode {
    s.tx.send(Command::Hush).ok();
    s.status.lock().unwrap().playing = false;
    StatusCode::NO_CONTENT
}

async fn get_status(State(s): State<AppState>) -> Json<StatusInfo> {
    Json(s.status.lock().unwrap().clone())
}

async fn events(State(s): State<AppState>)
    -> Sse<impl tokio_stream::Stream<Item = Result<Event, Infallible>>> {
    let st = async_stream::stream! {
        let mut last = String::new();
        loop {
            let cur = serde_json::to_string(&*s.status.lock().unwrap()).unwrap();
            if cur != last { last = cur.clone(); yield Ok(Event::default().data(cur)); }
            tokio::time::sleep(std::time::Duration::from_millis(250)).await;
        }
    };
    Sse::new(st)
}

fn deck_idx(s: &str) -> Result<usize, (StatusCode, Json<ErrRes>)> {
    match s { "A" | "a" => Ok(0), "B" | "b" => Ok(1), _ => Err(bad(format!("deck must be A or B: {s}"))) }
}

pub fn router(state: AppState) -> Router {
    Router::new()
        .route("/health", get(|| async { "ok" }))
        .route("/code", put(put_code))
        .route("/song/load", post(load_song))
        .route("/xfade", post(xfade))
        .route("/bpm", post(set_bpm))
        .route("/mute", post(mute))
        .route("/hush", post(hush))
        .route("/status", get(get_status))
        .route("/events", get(events))
        .with_state(state)
}

pub async fn serve(state: AppState, port: u16) {
    let listener = tokio::net::TcpListener::bind(("127.0.0.1", port)).await.unwrap();
    println!("API on http://127.0.0.1:{port}");
    axum::serve(listener, router(state)).await.unwrap();
}
```

## Risks / Open Questions

### 1. バッファまたぎのバー境界 — ✅ 確定（安全性優先）

**内容:** バー境界がオーディオバッファ（~5ms）の途中に来る場合、pending 適用タイミングをどうするか。

**決定:** デモ用ツールのため、**サンプル精度の厳密さより安全性（クリック・ノイズ・二重適用事故の回避）を優先**する。

**実装方針:**

- バッファ内スプリット（境界前後でコールバックを分割）は**行わない**
- pending 適用は「そのバッファ処理の先頭 or 末尾のどちらか一方」に寄せ、同一バッファ内で二度適用しない
- 状態差し替え時は既存どおり短時間（例: 5ms）のゲインランプでポップを抑える
- ずれは最大 1 バッファ分を許容する（体感上の小節感は十分）

---

### 2. sound 名の解決（波形 vs サンプル） — ✅ 確定（波形リスト → サンプルへフォールバック）

**内容:**  
`s("bd")` と `s("sawtooth")` は **見た目が同じ API** だが、Strudel 内部ではシンセとサンプルは別エンジン。表記だけ見ると `bd` が波形かサンプルか判別できない。

**これは Rust の型を分ける話ではない。** sound 名文字列の **解決順序** の話。

**決定:**

```
1. 固定波形リスト（sine/sawtooth/square/triangle + white/pink/brown 等）に存在する → シンセ
2. なければ SampleBank を探す → サンプル
3. どちらも無い → 明示エラー（現行曲は継続）
```

- **波形優先**（リストが短く、名前衝突 practically ほぼ無い）
- `note("c3").s("bd")` も **初期から可**（サンプルを pitch/speed で再生）
- `note("c3 e3").s("sawtooth")` は波形シンセ
- `s("bd sd hh")` は各イベント値を同じ `resolve_sound` に通す
- 先頭が `note` か `s` かは「パターン内トークンが音名か sound 名か」の別問題（併用可）

**デメリット（許容）:**

- 将来シンセ名を増やしてサンプルと同名になると衝突（波形優先で固定）
- タイポ時は両方失敗してからエラー（メッセージで「波形でもサンプルでもない」と書く）

詳細テーブルは **「Strudel 音源・エフェクト対応方針」** を参照。

---

### 3. 和音記法（`c3'maj7` 等） — ✅ 確定（初期から対応）

**内容:** 当初プランは「和音記法は非対応・展開済み音名のみ」としていた。

**決定:** Strudel 記法をそのまま流すことも想定するため、**和音記法を最初から対応**する。

**実装方針（Task 7 拡張）:**

- `note_to_hz` の前段で `c3'maj` / `c3'min` / `c3'maj7` 等を **半音オフセット列に展開**し、同時発音（複数 Voice）またはイベント列に落とす
- 対応するコード種は初期セットを明示（例: maj, min, maj7, min7, dim, aug, sus2, sus4）。未対応トークンはパースエラーで現行曲継続
- 曲ファイル例（ambient 等）に和音記法を残してよい（展開済み必須にしない）
- 詳細トークン表は実装時に Strudel / Tidal 系の慣例を参照して Task 7 に固定する

---

### 4. MCP ブリッジ方式 — ✅ 確定（stdio 直結しない）

**内容:** MCP を演奏プロセスに直結するか、HTTP ブリッジにするか。

**決定:**

- **演奏 CLI の起動は手動**（ユーザーまたは展示手順で `./strudel-rs` を先に起動）
- **MCP は HTTP への薄い転送層**（`strudel-rs mcp` が stdio で Hermes と話し、本体 `127.0.0.1:7878` に中継）
- stdio 直結（in-process で audio まで持つ）は**採用しない**。Hermes が MCP を複数回起動したときに **音声デバイス・Transport が多重起動**して厄介になるため

**結果として許容するもの:**

- 本体未起動時、MCP ツールは接続エラーを返す（仕様）
- MCP プロセスのクラッシュは演奏に影響しない（望ましい分離）

### 5. 曲A / 曲B / ミキサー層の 3 層構成 — ✅ 確定（旧「BPM 差の切替」を再定義）

**旧論点:** デッキ間で BPM が違う曲を載せると共有 Transport のせいで位相が崩れる。

**決定（構成）:** 実質 **3 層**にする。

| 層 | 役割 |
| --- | --- |
| 曲A（Deck A） | Song のロード・パターン評価・ボイス生成 |
| 曲B（Deck B） | 同上（並行再生可能） |
| **ミキサー層** | A/B **音量フェーダー**、**EQ・フィルター**、**A/B クロスフェードおよび曲切替** |

**意味:**

- デッキ側は「曲を鳴らすユニット」、ミキサー側は「混ぜて・整えて・切り替える」
- `xfade` / マスター的な A-B 切替 / チャンネル EQ は **mixer.rs** に寄せ、Deck の `gain` と責務を分離する
- Task 14 は「デュアルデッキ + Mixer」に読み替える（ファイル `mixer.rs` を追加）

**BPM について（旧リスクの残部）:**

- 両デッキは引き続き **共有 Transport（マスター BPM）** を見る
- 曲ファイルの `bpm` はマスター未設定時の初期値
- 異なる BPM 想定の曲を同時に「各曲固有テンポ」で鳴らすことはしない（デモ運用は同 BPM またはマスターに追従）

---

### 6. rmcp crate の API 安定性 — 📌 実装リスク（MCP「規格」そのものではない）

**内容:** MCP（Model Context Protocol）という**通信規格**の話ではなく、Rust から MCP サーバを実装するときに使う **ライブラリ `rmcp` の API がバージョン間で変わりうる**、という実装リスク。

**背景:**

- MCP 規格自体は JSON-RPC ベースのプロトコル
- 本プランは `rmcp` crate（`#[tool]` マクロ、stdio transport 等）でサーバを書く想定
- エコシステムが若いため、マイナーバージョンでもマクロ形状・feature 名・型名が変わることがある

**方針:**

- Task 18 着手時に crates.io / ドキュメントで **ピン留めバージョン**を決める
- マクロが合わない・ビルドが通らない場合は「詰まりプロトコル」: (a) バージョン固定で直す (b) 手書き JSON-RPC の最小 stdio サーバに退避、のどちらか
- ブリッジ設計（#4）のおかげで、MCP 実装の作り直しが演奏コアに波及しにくい

**ユーザー向け一言:** 「MCP のルールが曖昧」というより「Rust 用 MCP ライブラリの書き方がまだ落ち着いてないかも、という注意書き」。
