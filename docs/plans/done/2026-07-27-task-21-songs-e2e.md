# Task 21: 展示曲 + E2E（DJ 切替）

> 正本: [../2026-07-27_020000-strudel-rs-final.md](../2026-07-27_020000-strudel-rs-final.md)  
> 状態: **完了**（2026-07-27）

## Objective

デモ用の曲を同梱し、DJ 切替の一連の流れを NullBackend で自動検証する。  
Task 23 で追加したシンセ / orbit·duck / wavetable を聴ける曲も含める。

## 成果物

| パス | 内容 |
| --- | --- |
| `songs/techno1.strudel` | キック duckorbit(2) + FM ベース + pad orbit + compressor @ 126 BPM |
| `songs/ambient1.strudel` | `wt_organ` 和音 pad + `wt_bright` vib + sine arp（サンプル非依存） |
| `tests/e2e.rs` | 全曲パース、発音、DJ xfade techno→ambient |

既存の `*16` / `smoke` は変更せず残置。

## E2E ケース

- `all_bundled_songs_parse` — `songs/*.strudel` 全件パース
- `showcase_songs_use_task23_features` — techno1/ambient1 が Task 23 API を含む
- `ambient1_sounds_without_samples` — empty SampleBank でも発音
- `techno1_sounds_with_samples` — samples があるとき発音（無ければ skip）
- `dj_xfade_techno_to_ambient` — A→B 4-bar xfade 後 A unload・B 発音、finite / |x|≤1

## 検証

```bash
cargo test --test e2e
cargo test
```
