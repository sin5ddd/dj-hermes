### Task 25（任意・後半）: Punchcard / Pianoroll 端末 TUI

**Objective:** Strudel の `punchcard` / `pianoroll` に相当するノート時系列を、端末で表示する。

**前提:** Task 6（events）、Task 12（Engine）、Task 16 / live UI、Task 26（highlight / playhead）。

**Files:**
- Create: `src/viz.rs` — VizModel / collect_notes / render_pane_lines_ex
- Modify: `src/code.rs` — `note_to_midi`（`note_to_hz` と pitch パース共有）
- Modify: `src/live_ui.rs` — `BodyMode`、キー `F10`、`/viz`、左右 pane 分岐
- Modify: `src/cmd.rs` — HELP に `viz`
- Modify: `src/lib.rs` — `mod viz`

**設計（実装時の確定）:**
- **入口は `dj` live UI**（`play` は試聴用のため必須にしない）
- body を **highlight ⇔ punchcard** トグル。footer（EQ / XF / log / prompt）は維持
- 左右 = デッキ A / B（highlight と同じ分割）
- データは **UI が AST 再評価**（audio は `playhead` Atomic のみ）。Engine snapshot は使わない
- note トラックのみ描画。サンプルのみは案内文
- 和音トークンは Deck 同様 root 単音（`note_to_midi`）
- 依存追加なし（ratatui / feature flag なし）

**操作:**
```bash
strudel-rs dj songs/techno1.strudel songs/ambient1.strudel
# F10  … punchcard ⇔ highlight
# /viz  /viz on  /viz off
```

**検証:**
- 単体: `collect_notes` 階段ノート、muted 除外、render にブロック、`/viz` トグル
- 手動: note 入り曲で playhead が動くこと、highlight に戻れること

**非目標:** エディタ埋め込み、sample drum fold、`.color`、SSE 別プロセス、`play --viz` 必須化、scope/spectrum
